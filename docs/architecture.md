# Architecture

SkyForge treats autonomous air mobility oversight as a governance and regulatory problem.

## Inputs

- Vehicle class and corridor
- Separation distance
- Battery state
- Wind margin
- Override readiness
- Policy envelopes
- Event severity
- Policy triggers
- Handoff chains
- Resolution states

## Core idea

Urban air mobility systems need more than telemetry. They need:

- visible governance states
- replayable airspace provenance
- explicit override and sequencing chains
- operator-readable containment guidance

## Outputs

- Airspace risk overview
- Event replay lane
- Incident board
- API payloads for flight ops and governance systems
